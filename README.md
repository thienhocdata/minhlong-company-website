# Website Minh Long

Website giới thiệu riêng cho Minh Long tại TP. Hồ Chí Minh, tập trung vào bốn
nhóm dịch vụ: môi giới bất động sản, tư vấn thiết kế, xây dựng và đo đạc.

Trang cũng giới thiệu Minh Long Legal Agent như một lợi thế công nghệ đang được
hoàn thiện. Website không tự công bố số điện thoại, email, giấy phép hoặc số liệu
kinh doanh khi các thông tin này chưa được doanh nghiệp xác nhận.

## Chạy tại máy

Yêu cầu Node.js từ phiên bản 22.13.

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Kiểm tra trước khi phát hành

```bash
npm test
npm run lint
```

Mã nguồn dùng Next.js, React và vinext để tạo bản triển khai tương thích
Cloudflare Workers.
